# Проверка рецептов на очковые линзы и автовозврат клиентов для салонов оптики: n8n, PostgreSQL, Ollama qwen2.5-vl и Telegram (Docker Compose, Cloudflare Tunnel)

Набор к ролику «Проверка рецептов на сложные линзы». Мастер фотографирует бумажный бланк в закрытый Telegram-бот, локальная мультимодальная модель Ollama (qwen2.5-vl) читает диоптрии, n8n сверяет их с историей клиента в PostgreSQL и блокирует заказ при смене знака цилиндра или резком скачке диоптрий; врач подтверждает рецепт кнопкой. Через 11 месяцев бот напоминает клиенту о проверке зрения. Без абонентской платы за сервис: платите за сервер.

**Система не ставит диагноз и не заменяет врача. Она находит расхождения и ждёт решения врача, заказ на завод сама не отправляет.**

| `.env.example` | пример настроек: пароль базы, ключ шифрования n8n, домен, токен туннеля, чат врача `ADMIN_CHAT_ID`, список врачей `RX_DOCTOR_IDS`, чаты мастеров `RX_CHAT_IDS`, модель `OLLAMA_VL_MODEL` |

## Быстрый старт
1. VPS с Linux, Docker и Docker Compose; бот у @BotFather; туннель Cloudflare Zero Trust (маршрут на `http://n8n:5678`).
2. `cp .env.example .env`, значения сгенерируйте `openssl rand -hex 32` (пароль базы, ключ n8n), впишите домен, токен туннеля, chat_id и Telegram id.
3. `docker compose up -d`, затем `docker compose exec ollama ollama pull <модель из OLLAMA_VL_MODEL>`; создайте администратора n8n.
4. Замените пример карты 1001 в базе своими картами, импортируйте `optical_rx_n8n.json`, создайте учётные данные Telegram и PostgreSQL, активируйте сценарий.
5. Мастер шлёт фото бланка с подписью `карта 1234`; врач получает карточку с кнопками.

Аренда VPS: [Timeweb Cloud](https://timeweb.cloud/r/nf413716) (партнёрская ссылка, автор получает вознаграждение; условия на сайте, проверяйте актуальные).

## Две ловушки, которые закрывает набор
1. **Смещение таблицы между правым и левым глазом.** Модель возвращает подписи строк и столбцов, как напечатано на бланке; сценарий записывает значения, только если опознаны OD, OS и SPH, CYL, AXIS. Иначе ручной ввод. Врач подтверждает готовый JSON кнопкой.
2. **Кривое округление шага 0,25 диоптрии.** Проверяют и сценарий, и сама база (ограничения `CHECK` в `init.sql`): неверное значение в таблицу не попадёт.

## Честные ограничения
- Автор стек, сценарий и SQL-схему на живом сервере **не запускал** и точность распознавания qwen2.5-vl на реальных бланках **не проверял**. Логика узлов Code проверена в Node на подставных данных; SQL на PostgreSQL не запускался. Теги образов (`latest`), узлы Telegram, Postgres, удаление сообщений и имена параметров сверьте с документацией ваших версий.
- **Данные.** Локально остаются распознавание (Ollama), сценарий (n8n) и база (PostgreSQL): рецепты не отправляются во внешние нейросети. Но фото бланка проходит через серверы Telegram, а трафик через Cloudflare Tunnel. Обезличивайте бланк до отправки: закройте ФИО, телефон и дату рождения; клиент в базе это номер карты. Бот удаляет фото из чата мастера после обработки (проверьте в своей версии Bot API).
- Рецепты это медицинские данные особой категории (152-ФЗ): согласие клиента, хранение и передачу проверьте у юриста. Это не юридическая консультация.
- Точность зависит от бланка, света и почерка. Пороги сравнения с историей (sph 1,00, cyl 0,75, ось 20 градусов) условные: подберите их вместе с врачом. Шаг 0,25 дптр проверьте по справочнику оптометрии.
- Автовозврат: Telegram не даёт боту писать первым, клиент должен сам запустить бота и дать согласие (`consent_recall`). Срок 11 месяцев меняется в запросе узла.
- Для мультимодальной модели нужны ОЗУ и желательно видеокарта; на CPU распознавание одного бланка может занимать десятки секунд (не замерялось).
- Цифры 40 000 ₽, 90 000 ₽ и 11 месяцев в ролике иллюстративные параметры и оценки владельца.
- Туннель открывает доставку сообщений на ваш n8n: редактор закройте через Cloudflare Access. Условия бесплатного Cloudflare Tunnel проверяйте на сайте Cloudflare.
- Нужен бэкап базы рецептов по правилу 3-2-1: 3 копии, 2 носителя, 1 вне сервера; не удаляйте оригиналы, пока восстановление не проверено.
